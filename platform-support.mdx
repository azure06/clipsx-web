## Current status

| Platform | Architecture | Package | Status |
| --- | --- | --- | --- |
| Windows | x64 | Signed `.exe` | Available in v0.1.0 |
| Linux/X11 | x64 | AppImage | Available in v0.1.0 |
| Linux/X11 | x64 | `.deb` | Available in v0.1.0 |
| macOS | Apple Silicon | Signed, notarized `.dmg` | Available in v0.1.0 |
| macOS | Intel | Signed, notarized `.dmg` | Available in v0.1.0 |

An artifact appears on the ClipsX download page only after its platform
certification and publishing checks pass.

<Warning>
  Do not infer availability from a version number, repository tag, or file name.
  Use only a build that the [download page](https://clipsx.app/en/download)
  marks as available.
</Warning>

## Platform notes

- Linux v0.1.0 supports X11. Wayland is outside this release's support.
- macOS packages use Developer ID signing, notarization, and stapling.
- [Release notes](https://github.com/azure06/clipsx/releases/tag/v0.1.0)
  describe installation, updates, database compatibility, and recovery.
