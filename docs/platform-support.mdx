## Current status

| Platform | Architecture | Package | Status |
| --- | --- | --- | --- |
| Windows | x64 | `.exe` | Coming soon |
| Linux | x64 | AppImage | Coming soon |
| Linux | x64 | `.deb` | Coming soon |
| macOS | Apple silicon and Intel | `.dmg` | Coming soon |

An artifact appears on the ClipsX download page only after its platform
certification and publishing checks pass.

<Warning>
  Do not infer availability from a version number, repository tag, or file name.
  Use only a build that the [download page](https://clipsx.app/en/download)
  marks as available.
</Warning>

## Platform notes

- The first Linux release targets X11.
- macOS is not a primary download until signing, hardened runtime, notarization,
  and stapling are complete.
- Current release metadata identifies version `0.1.0`, but every configured
  target remains unavailable.
