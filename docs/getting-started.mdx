## Before you begin

ClipsX does not currently publish a certified desktop installer. Windows x64
and Linux x64 are the first release targets. macOS remains unavailable until
its signing and distribution path is complete.

<Info>
  An account is optional for the core desktop product. Sign in only when you
  want supported settings sync or other account services.
</Info>

<Steps>
  <Step title="Check release availability">
    Open the [download page](https://clipsx.app/en/download). Install only a
    target explicitly marked as available.
  </Step>
  <Step title="Copy supported content">
    After a release is available and installed, copy content normally from an
    application on your device.
  </Step>
  <Step title="Open ClipsX">
    Use the configured shortcut to open clipboard history, then search or browse
    for the captured clip.
  </Step>
  <Step title="Choose a representation">
    Preview the representations ClipsX retained, such as rich content and plain
    text, then choose the form you want to paste or copy.
  </Step>
</Steps>
